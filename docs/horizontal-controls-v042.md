# Grain 0.4.2 橫向滑桿

2026-10-02。相機主畫面的 ISO、快門、曝光、白平衡、光圈與變焦滑桿改為左右拖動。

## 操作

- 點相機控制格或中央變焦鍵，向上浮出一條橫向滑桿。
- 往右增加要求值，往左減少；ISO、快門時間與倍率保留原有對數刻度，白平衡預設與光圈仍按裝置提供的順序切換。
- 名稱與目前要求值顯示在滑桿上方；右側保留 AUTO、曝光 0 或變焦 1× 還原。
- 變焦在錄影中仍可調整，雙指變焦照常使用。對焦後在觀景窗上下滑曝光的手勢沿用原有操作。
- 再點目前控制格、點觀景窗對焦或返回可收起滑桿；控制格、變焦鍵與觀景窗維持位置。

## 介面與效能

滑桿浮在整組底部控制上方，左右各留 12dp，較寬視窗限制面板寬度至 480dp。採用標準 Material 橫向 Slider，觸控高度至少 48dp，支援既有輔助操作；物理右方向固定增加數值。

移除直式版本的旋轉與交換寬高量測。直接拖動立即更新要求值，放手後不加入慣性、數值追趕或額外相機重新綁定。保留短淡入淡出、文字格式化記憶與分區狀態更新。

裝置能力、ISO／快門範圍、錄影快門上限、AUTO 還原與 LUT 處理流程沿用既有實作。
