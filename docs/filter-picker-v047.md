# Grain 0.4.7 濾鏡選擇與切換

原本把所有 LUT 放在一條文字列，需一直橫滑找名字，選完再關閉大面板；各款也共用目前強度，上一款若是 0%，新濾鏡看起來沒有套用。0.4.7 改成觀景窗底部的系列卡片，快門保持可點，開關選擇器不改變觀景窗尺寸。

## 系列與瀏覽

- 分類為全部／富士／Kodak／Grain／匯入，沒有項目的分類不顯示。
- Portra 160／400／800 合成一張 Portra 卡片，首次預設 400；CLASSIC 合併 Chrome／Neg.；ETERNA 合併一般／Bleach Bypass。版本在卡片下方選擇。
- 分組根據已知素材 ID。使用者匯入的檔名即使同名，也不自動併入內建素材，避免錯認來源。
- 點系列或版本立即套用；使用者左右拖動停住時套用中央系列。滑動途中不連續切換 LUT。
- 開啟選擇器、切換分類、程式自動置中只改瀏覽位置，不自動套用第一款。金色框線、勾選及無障礙選取語意代表真正正在使用的系列，與單純瀏覽位置分開。
- 每個系列記住最後選的版本，每款 LUT 分別保存強度。首次選用預設 100%，切回恢復自己的值，選原色移除 LUT 並保留獨立的調色設定。重選目前版本不重設輸入色彩或強度。
- 匯入完成沿用同一切換流程。拍照、開始錄影、返回鍵或點觀景窗可收起選擇器；點觀景窗仍可對焦。

## 介面與效能

使用既有黑金主題、Compose Material 選取元件、48 dp 觸控區與可捲動高度；小螢幕、橫向或大字體不把操作列推出螢幕。卡片是底片包裝式的名稱與品牌標示，效果由觀景窗呈現，沒有生成或宣稱實拍縮圖。新增四個 Compose 設計預覽，包括 320 dp、一般直向、橫向及 1.5 倍字體；本次已編譯，未以裝置截圖驗證。

分類與系列目錄記憶快取，Pager 只建立目前需要的卡片；沿用現有 GPU shader。切換僅在停住或點選時更新 LUT，沒有新增每幀 CPU 影像讀取、LUT 重建或相機重新綁定。強度滑動時只更新影像設定，結束或切換才非同步保存；不在每個滑動事件寫偏好。

作者、來源與授權移至「調色與濾鏡資訊」，所有既有連結保留。匯入 LUT 在選擇器與設定皆可使用，沒有相機權限也能從設定匯入。沒有新增可見手勢／操作說明。

Pager 使用現有穩定 Compose Foundation API，[Android 官方文件](https://developer.android.com/develop/ui/compose/layouts/pager) 說明 lazy 建立卡片、程式置中及 settledPage。實作另以 DragInteraction.Start 區分使用者拖動和程式動畫，避免把瀏覽初始化誤判為選取。
