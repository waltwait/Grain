# Grain 0.4.8 三個英文品牌分類

依使用者要求，類別固定為 FUJIFILM／KODAK／GRAIN。下方只有各款濾鏡卡片及強度，移除系列版本子列；Portra 160／400／800、CLASSIC Chrome／Neg.、ETERNA／Bleach Bypass 等各款直接可選。卡片不再重複品牌或顯示版本數量，浮層也因此少一列。

自訂匯入與舊示範 LUT 放在 GRAIN。分類依內建 ID 與匯入狀態判斷，不以匯入檔名推論成富士或柯達素材。每款 LUT 在三個類別中恰好出現一次；不顯示全部／匯入等額外類別。類別即使暫無素材也保留，顯示空狀態；一般 Release 沒有官方富士 LUT 時會從可用的 GRAIN 開始。

開啟浮層時先顯示目前濾鏡所屬品牌；使用者切換品牌只是瀏覽，不更換正在套用的 LUT。點卡片或使用者左右滑動停住時直接套用各款，程式置中不觸發選取。原有每款強度記憶、第一次 100%、原色、匯入、作者／來源／授權與快門直接操作保留。移除不再使用的系列資料模型與版本偏好寫入，既有目前 LUT 與強度偏好仍可沿用。

這次沒有更換 LUT、shader、白平衡或相機綁定流程，也沒有新增可見操作說明。四個 Compose 預覽已改用單層選擇器並通過編譯，涵蓋直向、320 dp、橫向與 1.5 倍字體；未進行實際預覽截圖或裝置操作。
