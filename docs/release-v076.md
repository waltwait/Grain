# Grain 0.7.6

0.7.5 發布前審查留下的小問題一次清掉。版本 0.7.6／versionCode 39，沿用正式簽章、套件與十款富士 LUT。沒有新功能。

## 變更

- **搜尋：**
  - 中文鍵盤打的全形數字與全形空格（`１０／４`）能搜了。
  - `10月4號` 算日期。
  - 像日期的詞同時當文字搜：以前膠片名裡的「1.5」永遠搜不到，因為會被當成 1 月 5 日。
  - 關鍵字改成只切一次，不再每張照片重切。
  - 「今天」過了午夜不再停在舊的一天。
- **膠片索引：**
  - 讀取暫時失敗的照片下次會再讀，不再被永久記成「沒有膠片」。
  - 寫檔用不重複的暫存檔名，避免兩次背景工作同時寫壞索引。
  - 「你用過的膠片」標籤只列還存在的照片的膠片。
- **編輯：**
  - 被 MediaStore 改名的原圖重複檔（`…_original (1)`）算原圖，不會再被當成編輯成品出現在格子牆。
  - 只勾一個或沒勾濾鏡時，內部工作識別就是來源本身。
  - 取消勾選時濾鏡分組不會被拉走。
  - 多選卡片的無障礙角色改成核取方塊。
  - 編輯 tab 首頁在相簿讀取失敗時也顯示錯誤與重試。
- 網站（不屬於 App）：下載主頁搬到這個 repo 並加上圖示，見 [下載主頁說明](download-page.md)。
