# Grain 0.4.9 拍照與存檔回饋

依使用者要求，成功存檔不再顯示儲存位置或跳出通知。相機畫面移除 SnackbarHost，照片、影片、匯入照片與 LUT 匯入／移除的成功訊息一併移除。錯誤及必要提示改放在底部固定文字區，五秒後清除；過期計時器不會清掉較新的訊息。相簿縮圖、快門與觀景窗的動畫只表示目前進度，不新增可見操作說明。

## 回饋時機

- 接受拍照：快門內側縮至 97%，以 160 ms 回復。按鈕的觸控範圍維持固定。
- 相機完成影像回呼：觀景窗疊加 16% 黑色遮罩，140 ms 淡出。沒有拍到影像或只有按下快門時不觸發這項回饋。
- 確認照片存檔並嘗試載入縮圖後：更新相簿縮圖，180 ms 淡入；縮圖內側以 200 ms 回復尺寸，金色細框在 260 ms 內淡出。儲存失敗不顯示成功回饋。
- 拍攝或存檔超過 250 ms 才顯示細進度提示：拍攝中在快門外側，存檔中在相簿縮圖下緣。影片停止後的存檔也使用縮圖進度提示。

每次拍照有獨立 request ID，分開追蹤接受、拍到影像與儲存完成事件，過期或重複回呼不能結束較新的拍攝。匯入照片及影片只更新儲存版本，不觸發拍照的觀景窗效果。組件初次顯示、回到相機或載入既有縮圖時不重播拍照動畫。

讀取 Compose 的 MotionDurationScale，系統關閉動畫時不播放上述位移／淡出，進度提示改為靜態線段並保留無障礙狀態。原有拍照、開始／停止錄影、相簿的無障礙描述仍保留。

## 效能與存檔處理

快門縮放使用 graphicsLayer，遮罩與框線只在繪製階段讀取動畫值，閒置時不繪製透明遮罩或框線。動畫不搬動控制元件或改變觀景窗尺寸，不複製相機影像；縮圖沿用背景載入的 160 × 160 bitmap。底部預留單行訊息空間，避免訊息出現時推動控制列；大字體可能增加這個固定區域的高度。

照片與匯入照片的暫存檔建立移入 try/finally，建立失敗也會回復 busy 狀態。MediaStore 發布與可選原圖儲存流程沿用既有實作。縮圖讀取失敗回傳空預覽，保留已成功儲存的 URI，不再顯示拍照失敗；coroutine 取消仍向上傳遞。照片仍需等縮圖讀取嘗試結束才解除 busy，這次未量測或宣稱存檔速度提升。

Debug APK、AndroidTest APK 與 R8 Release 均建置成功。完整檢查耗時 1 分 7 秒；最後修正 debug 預覽的 KTX 提示後，Debug／AndroidTest／JVM／Lint 再驗證成功，耗時 16 秒。新增四個 Compose 預覽，涵蓋直向、320 dp、橫向與 1.5 倍字體，已編譯，未實際渲染截圖。

新增裝置測試：拍照成功不產生文字訊息、確認成品 JPEG 可解碼、觀景窗／快門／相簿範圍在拍照前後相同，以及錯誤只出現在固定文字區；既有影片測試增加成功後文字區為空的檢查。這些測試已編譯，尚未連接手機執行，沒有新裝置截圖、GPU 驗證或動畫幀率量測。S24 動畫手感、直橫向／大字體實際配置與手動色溫仍待實機驗證。
