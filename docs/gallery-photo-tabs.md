# 照片與編輯 tab 工作版

照片檢視改為黑底滿版，頂部提供返回圖示與照片張數，底部提供「照片／編輯」兩個 tab。照片保留左右滑動、雙指縮放與雙擊還原；單點淡入／淡出工具列，沒有放大或上一張／下一張按鈕，也沒有手勢說明文字。影片播放／暫停改用圖示，輔助功能保留可讀標籤，影片不提供照片編輯 tab；0.6.5 補上影片檢視的系統安全邊界，避免底部控制列被導覽列遮住。

編輯 tab 直接使用目前照片，重用既有 GPU 濾鏡預覽、原圖比較、品牌分類與強度控制，不顯示換照片按鈕。兩個 tab 保存各自畫面狀態；照片保留頁碼、縮放及平移，編輯保留已解碼來源、濾鏡與強度。SavedStateHandle 記錄來源 URI，回到相同照片時不再次複製來源或重設濾鏡。離開檢視頁才清理編輯暫存。

儲存沿用另存照片流程，不覆寫原圖；儲存中停用 tab、返回與翻頁。相簿加入新照片後依 URI 保持原來編輯的照片，避免排序變更造成換圖。相簿主頁的外部匯入功能仍使用獨立編輯頁。

2026-10-04 執行 `testDebugUnitTest`、`lintPersonal`、`assembleDebugAndroidTest`、`assemblePersonal` 成功，最後一輪耗時 2 分 12 秒。143 項 JVM 測試通過，0 失敗／錯誤／跳過；lint 0 錯誤、22 警告。裝置測試補充 tab 往返保留縮放、單點工具列、編輯 bitmap 與強度保留，以及儲存後維持原始來源的檢查，已完成編譯。ADB 裝置清單為空，這些觸控與 GPU UI 測試尚未在手機執行。
