# Grain 0.4.1 相機介面調整

2026-10-02。這一輪落實四項主畫面調整，讓拍攝操作更接近原生相機，同時沿用 Grain 的黑底與暖金選取色。

## 畫面與操作

| 區域 | 調整 |
| --- | --- |
| 頂部 | 閃光燈／影片畫質、短底片名稱、設定；取消厚重背景膠囊，保留 48dp 以上觸控高度與完整底片名稱的朗讀描述 |
| 變焦 | 一個 48dp 圓形倍率按鈕，置中於控制列上方；可點開直式滑桿，也可在觀景窗雙指縮放，錄影中沿用同一套控制 |
| 相機控制 | ISO、快門、曝光、白平衡常駐透明控制列；裝置支援可變光圈時才增加光圈格，不支援的參數停用 |
| 色彩 | 一般文字與圖示採白色，選取的控制、滑桿與拍攝模式使用暖金；錄影按鈕與計時保留紅色 |

點選參數時，直式滑桿浮在整組底部控制上方。控制格、倍率按鈕與觀景窗不因滑桿展開而改變位置；左右邊緣保留距離，橫向較矮時縮短滑桿。AUTO、曝光歸零與 1× 還原操作沿用原有行為。

對焦仍以框線動畫表示；對焦完成後上下滑調整自動曝光補償。手動模式沿用 ISO／快門控制。這一輪沒有新增模式滑動、對焦太陽圖示或更改相簿進入流程。

## 動畫與效能

- 滑桿使用 100ms 淡入及少量上移、90ms 淡出及少量下移，不做高度展開或模糊運算。Compose 動畫沿用系統動畫時間縮放。
- 直接拖曳滑桿時立即更新要求值，不加動畫追趕手指。
- 只有一個浮動滑桿；底部高度依實際量測保留，以適應字體大小。
- 控制值依自己的參數記憶格式化結果，拖曳變焦時不反覆格式化快門、曝光等未變動文字。
- 沿用錄影計時與相機回報值分區更新、GPU LUT 預覽及有限相簿快取；沒有新增影像處理或相機重新綁定流程。

## 設計預覽

Android Studio 可開啟 `app/src/debug/java/tw/luma/camera/ui/NativeCameraChromePreview.kt`，查看 320dp、640×300dp 橫向及 1.3 倍字體的控制區預覽。預覽使用代表性能力與背景色，不啟動相機；只納入 debug 版本。預覽原始碼編譯不代表已完成畫面渲染或實機驗收。
