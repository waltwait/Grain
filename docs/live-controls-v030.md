# Grain 0.3.0 即時相機控制

## 操作

- 觀景窗下方常駐 ISO、快門、曝光、白平衡、單一變焦倍率按鈕；鏡頭有可調實體光圈時增加光圈格。
- 點格子向上展開一條直式滑桿，上滑增加、下滑減少；再次點同一格、點觀景窗或返回鍵會收起。
- ISO／快門格會以目前感測器值進入手動曝光，底部 AUTO 恢復自動曝光。不支援的格子停用。
- 變焦倍率依鏡頭實際範圍提供，採對數刻度；倍率按鈕、滑桿與雙指縮放在 RECORDING 狀態仍可使用，STARTING／STOPPING 暫停輸入。
- 成功對焦或完成固定焦鏡頭測光後，單指向上／下滑調整自動曝光。每 80 dp 約一級 EV，依裝置 EV 步長量化及限制範圍。顯示暫時曝光值，手指放開 1.2 秒後消失。
- 雙指操作取消單指曝光手勢，不會在抬指後誤觸對焦／曝光；橫向滑動不調整曝光。
- 手動模式的 EV 格停用，滑動不修改 ISO／快門。白平衡可使用實體 K 色溫（若支援）或預設；色偏與 AWB 鎖定留在更多設定。
- 錄影手動快門以 1/30 秒為上限，降低長曝導致錄影幀率下降的風險；進入手動模式時，在感測器範圍內補償 ISO 以維持亮度。

## 實作

觀景窗仍使用 CameraX PreviewView 的 meteringPointFactory 對應對焦座標。手勢由原生 GestureDetector／ScaleGestureDetector 分流，控制格使用 Compose 與現有穩定 Material Slider。直式滑桿同時旋轉量測、繪圖與觸控座標，保留 Material 的進度語意及螢幕閱讀器操作。

倍率與 EV 的單獨變更使用 CameraControl.setZoomRatio／setExposureCompensationIndex，不重新綁定相機、Recorder 或 LUT processor。錄影狀態不會成為 ISO／快門／變焦／曝光輸入的停用條件；忙碌、啟動及停止存檔期間會停用。其他拍攝設定仍由既有 Camera2 interop 套用。

參考：[CameraX 即時相機控制](https://developer.android.com/media/camera/camerax/configuration)、[Compose 動畫](https://developer.android.com/develop/ui/compose/animation/quick-guide)。

## 驗證

手機目前不在使用者手邊；本版不執行裝置測試、不安裝。

電腦端：APK、裝置測試 APK 編譯及 30 項 JVM 測試通過；包含曝光方向、螢幕密度、感測器步長、限制邊界和大範圍倍率／ISO／快門刻度測試。靜態檢查 0 錯誤，20 項警告；未把警告或編譯成功視為實機驗證。

裝置測試已更新以測試直式滑桿觸控，以及錄影中滑桿／雙指變焦後仍持續計時及產生可解碼 LUT 影片；僅完成編譯，尚未執行。0.2.0 的兩項裝置測試失敗狀態不視為本版已解決。

待手機到位：

1. 確認單一倍率按鈕展開位置、上下滑方向、窄畫面與橫向使用、連續開關格子及大字體。
2. 拍照／錄影中點對焦後，上下滑改變畫面亮度，EV 依鏡頭邊界限制；水平滑動及雙指抬起不觸發曝光／對焦。
3. ISO／快門從 AUTO 進入 M，再恢復 AUTO；確認影片中手動參數不停止錄影，且畫面、實際 capture result 與設定吻合。
4. 開始錄影後以滑桿與雙指來回變焦，確認計時不中斷、影片內容確實變焦、套用 LUT、音軌設定及停止存檔正常。
5. 前鏡頭／固定焦或不支援手動感測器的鏡頭，控制停用與測光回饋正確；切換模式、返回、切到背景後不殘留滑桿／曝光提示。
