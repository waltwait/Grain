# Grain 0.7.3

相機畫面的小調整：閃光燈一點就開關、左下角縮圖顯示最近一張、設定面板拿掉「完成」按鈕、相簿標題不再跳動。版本 0.7.3／versionCode 36，沿用正式簽章、套件與十款富士 LUT。

## 變更

- **閃光燈直接點：** 拍照模式左上的閃光燈圖示點一下就切換，不再開設定面板；設定裡的「拍照閃光燈」那一列移除。沒有閃光燈（例如前鏡頭）、手動曝光、拍照存檔中或錄影中，圖示變暗、點了沒反應，也不會顯示成開啟（先前切到前鏡頭後圖示仍是金色但實際不會閃）。無障礙標籤為「閃光燈已開啟／已關閉／無法使用」。錄影模式左上維持影片畫質，沒有閃光燈。
- **左下角縮圖顯示最近一張：** 以前只有開 App 後拍的才會出現，重開就空了。現在開 App 時在背景載入 Grain 拍的最新照片或影片（`Pictures/Grain`、`Movies/Grain`，限本 App 擁有），拍了新的就換成新的；編輯成品在 `Pictures/Grain Edits`，不會取代它；一張都沒有時維持原本的空圖示。
- **設定面板沒有「完成」按鈕：** 設定與「調色與濾鏡資訊」共用同一個面板，兩者都移除；仍可下滑、點背景或用返回手勢關閉。
- **相簿標題不跳動：** 「Grain」下方那行小字在照片 tab 有張數、編輯 tab 單張時沒有，置中的標題因此上下移動；現在那一行永遠佔位。
