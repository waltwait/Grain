# Grain 0.7.4

閃光燈新增「自動」模式、編輯 tab 顯示編輯成品張數，並依設計評審整理一批 UI 細節。版本 0.7.4／versionCode 37，沿用正式簽章、套件與十款富士 LUT。

## 變更

- **閃光燈自動模式：** 拍照畫面左上的閃光燈圖示點一下輪流切換「關 → 自動 → 開 → 關」。自動時白色閃電右下角有金色小「A」，開時為金色閃電加深色圓底。沒有閃光燈、手動曝光、存檔中或錄影中時圖示變暗並顯示成關；每次開 App 與切換拍照／錄影都回到關。自動對應 CameraX 的 `FLASH_MODE_AUTO`；無障礙標籤為「閃光燈已關閉／自動／已開啟／無法使用」。
- **編輯 tab 顯示張數：** 相簿標題下方那行小字，編輯 tab 沒有批次時顯示編輯成品的張數（沒有成品顯示 0），批次編輯中仍顯示位置如 `2 / 5`；照片 tab 仍顯示照片與影片總數。
- **UI 調整（設計評審）：**
  - 選取中的標籤（相簿的全部／照片／影片、編輯頁與相機濾鏡面板的品牌標籤、白平衡的兩個標籤）改用淡金底加金字，不再是灰紫色。
  - 編輯頁預覽上「原圖／換照片」按鈕的底色由 40% 加深到 65%，金字在純白照片上的對比由約 2:1 提高到約 5:1。
  - 「原色」全部改稱「無濾鏡」，避免和「原圖」混淆（共 6 處）。
  - 更新頁的下載進度條與按鈕內的轉圈加上螢幕閱讀器描述。
  - 與主題 surface 相同的深色字面值改用主題色（畫面不變），其餘深色集中成共用常數。
  - 橫向畫面移除與頂部設定圖示重複的「設定」文字按鈕。
- 未處理：主色金 `#FFD45B` 與 KODAK 色條 `#D4A955` 太接近（主觀，待實機看）、檢視頁的分享與刪除（新功能）。
